# CyVR Player 0.4.6 Alpha 1

- Software AV1 fallback with dav1d 1.5.4, including ARM64 SIMD assembly and 8/10-bit decoding.
- MVC/H.264 stereo with the BSD edge264-mvc decoder, including dependent-view MPEG-TS PIDs in the same program. Two-view MV-HEVC uses FFmpeg and timestamp-matched eye pairing. Output keeps full-width SBS samples, selects stereo automatically and retains eye inversion controls.
- ClearKey JWK import/removal for CENC AES-128 media with user-supplied keys. Track selections and the key-file URI survive activity changes; key bytes are not stored in the application checkpoint.
- Correct original-packet retention when switching from hardware startup to software decoding, bounded startup queues and raw AVC/HEVC/TS format hints.
- Fix surround downmix saturation with normalized coefficients and 1 dB of codec headroom, keeping stereo unity gain. Prebuffer audio, read ahead independently of the decoded video queue, preserve continuous PCM across rounded MKV timestamps and recover from starvation without dropping late samples. Tune the AAudio buffer to native bursts and report actual underrun/overrange counters.
- Fix immersive trigger capture: application buttons remain on the main panel after pressing, so **Full interface**, **Compact controls** and other player actions activate on release instead of being misrouted to the dock.
- Portable stereo/10-bit/JWK regression tests and headless Quest codec, audio-clock, container/subtitle and Gaussian performance probes.

Windows and both Android Alpha variants build and pass package checks. Nine CTest suites and media/container/compatibility/audio integration tests pass. On Quest 3, AV1 8/10-bit, MVC, two-PID MVC, MV-HEVC and CENC produce the same decoded image hashes as the PC references. AHardwareBuffer/Vulkan presentation, AAudio startup, paused seek/resume, MKV track selection, ASS/PGS subtitles, chapters and GPU subtitle blending were exercised. All 174 image-processing GPU cases pass on Adreno.

Gaussian synthetic tests at 1920 × 1920 per eye measured approximately 10–12 ms per stereo frame for 100,000 splats in Native/CAS/GSR, and 21 ms with FSR. At 1,000,000 splats, the corresponding times were approximately 45–46 ms and 54 ms. These include CPU submission and completion waits; they are not compositor FPS, representative-scene guarantees or thermal qualification.

Audio PCM levels and sample counts match FFmpeg references for generated stereo 44.1 kHz, AAC 5.1 and FLAC 7.1 media. Nine final Quest playback cases, including chunked MKV and pause/seek/resume, report no PCM starvation, sample gaps/loss, clipping or AAudio underruns. These counters do not replace listening acceptance on the headset.

MVC currently requires progressive 8-bit 4:2:0; MV-HEVC supports two views and available software pixel formats, with 8/10-bit paths tested. High-resolution/high-rate software decode remains CPU-limited. Blu-ray ISO/menu/protected-disc support is not added. ClearKey import does not acquire licenses or implement proprietary Widevine/PlayReady/FairPlay systems. Physical binocular comfort, audible synchronization and worn-headset controller gestures require user validation.

The APK starts in a Quest-managed 2D window with optional immersion. Updating with the existing signing identity preserves app data. This is a testing Alpha, not a store package. CyVR Player remains GPL-3.0-only; the supplied CyVR_UI snapshot remains MIT. Exact dependency sources and build instructions accompany the APK.
