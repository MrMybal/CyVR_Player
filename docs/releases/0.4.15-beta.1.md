# CyVR Player 0.4.15 Beta 1

[Français](0.4.15-beta.1.fr.md) · [README](../../README.md) · [Published release](https://github.com/MrMybal/CyVR_Player/releases/tag/v0.4.15-beta.1)

This Beta brings the latest playback controls, continuous library browsing, subtitle styling and CyVR_UI 0.9.1 window interactions to the Quest player.

- Browse files in tile or list view with continuous joystick scrolling, a vertical scrollbar and up to nine retained previews.
- Use the compact immersive playback bar with its drag handle, timeline, transport and shortcuts. Only this compact bar auto-hides after three seconds; a deliberate press restores it. Closing the full interface returns to compact controls, while minimizing keeps the full window available for restoring.
- Grip the full immersive interface to move it, or grip an edge/corner to resize it. A minimal window bar reveals its icons on hover. Window preferences are available in Settings.
- Grab the movie with a trigger to move or rotate it independently of the interface. Joystick left/right turns the view outside the UI; grip + trigger controls zoom. VR180/360 use rotation for spatial placement.
- Adjust subtitle size, color, opacity, outline, shadow, style and placement, including independent caption distance in VR.
- Keep the native C++/Vulkan 2D launcher, optional immersion, video format controls, CAS/FSR/GSR filters, cinema geometry, environments, Ambilight, container tracks and existing media support.

## Downloads

- **CyVR_Player-0.4.15-beta.1-arm64.apk** — Meta Quest Android application, with the 2D launcher and optional immersive playback.
- **CyVR_Player-0.4.15-beta.1-sources.zip** — matching player sources, the MIT CyVR_UI source snapshot, dependency source archives and build instructions.
- **SHA256SUMS.txt** — checksums of the APK and source archive.

Install the APK over an existing Alpha using `adb install -r` or your usual sideloading tool. It retains the existing package and signing identity for upgrades. Keep the installed app's data when updating.

This is a testing prerelease. Media compatibility and performance depend on the file, selected filters and headset. Controller feel, visual quality, audiovisual synchronization and sustained performance still need testing while wearing the headset. The bundled source archive documents how to rebuild the same Beta profile.

## Status and documented limitations

The documented limits include service DRM, disc menus and protected disc payloads, fisheye/cubemap projections, SMB/NFS shares and unsupported Gaussian formats. HDR is converted to SDR; multiview codecs and software fallback can be expensive on the headset CPU. See the [user guide](../user-guide.md#scope-limits) for details.

The release does not publish a bug-by-bug ticket list. Consult or contribute to the [issue tracker](https://github.com/MrMybal/CyVR_Player/issues); the limitations above are separate from confirmed bug tickets.

## Release validation

All 14 Windows CTest suites pass, including the shared window interactions, application state transfer, video placement, GPU rendering and media core tests. The Android Beta is an optimized ARM64 build with debugging disabled, stripped native libraries, a verified APK signature, 16 KiB ELF/ZIP alignment and packaged dependency notices.
