# CyVR Player 0.4.4 Alpha 1

Experimental ARM64 build for Meta Quest. Requires Android API 32 and Horizon OS v69 or later. The app opens in a native 2D window; immersive video remains optional.

- Video placement stays independent when the immersive controls panel is moved and released. **Recenter video** moves only the video.
- Native playback, CAS, FSR 1 and Snapdragon GSR 1 share the independent video placement.
- Includes the timeline, static browser previews, local files and streams, image corrections, zoom, and hide/show controls.
- The Alpha APK uses an optimized, non-debuggable build and the existing development signing identity, allowing updates over prior CyVR Player development APKs with the same key.

## Install

Download `CyVR_Player-0.4.4-alpha.1-arm64.apk` and install it with `adb install -r`. Package ID: `com.cyvr.player`. It replaces the existing player APK; do not uninstall first if you want to retain app data.

## Known limits

**Video playback currently has no audio output.** Audio/A-V synchronization, subtitle display, HDR tone mapping and Gaussian Splatting playback remain unimplemented. This Alpha has not received a new on-headset validation pass. Stream/provider compatibility, real tracking-origin transitions, sustained performance and thermal behavior still require device testing.

This is a testing prerelease signed with a development identity, not a store package.
