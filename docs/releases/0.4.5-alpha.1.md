# CyVR Player 0.4.5 Alpha 1

- Broader Android FFmpeg decoder/demuxer profile with hardware-first video and explicit software fallback.
- Native stereo audio output with AAudio and an audio-driven video clock.
- MKV/container video and audio track selection, subtitle selection/disable, external subtitles, chapters and persisted track choices.
- Styled ASS/SSA through libass, font attachments, text and bitmap subtitle overlays that remain visible when playback controls hide.
- PQ/HLG HDR-to-SDR tone mapping before image corrections and Native/CAS/FSR/GSR reconstruction.
- Compact immersive timeline, play/pause, previous/next file, full-interface button and automatic hiding after three seconds without controller activity.
- Gaussian PLY/32-byte SPLAT scenes and internal independent-frame `.splatseq` animation, using per-eye Vulkan GPU visibility/sorting/rasterization.

The APK launches in a Quest-managed Android 2D window; immersion remains optional. Updating with the same signing identity preserves application data. This Alpha is for testing and is not a store package.

Validation: seven desktop CTest suites, 174 image GPU cases, multi-track MKV and PGS subtitle tests, Gaussian GPU/sequence/control tests, and sixteen desktop media/stream integration cases. ARM64 Alpha builds and package checks pass. The default APK was installed on Quest 3 and exercised through 2D/immersive transitions, reversible window resizing, HDR/PQ hardware decoding/rendering, AAudio startup, three-second auto-hide and key wake. Runtime rendering reported no error. Audible output, HDR appearance, physical controllers and sustained mobile/Gaussian performance still need manual qualification.

See README for exact codec/protocol and Gaussian limits. AV1 needs supported hardware in this Android profile; DRM, MVC/MV-HEVC stereo, audio-only playback, Android DASH/libSRT and Gaussian deformation codecs are not implemented. Gaussian scenes are limited to 1,000,000 splats/frame and the backend's packed representation. `.splatseq` is an internal frame manifest, not a universal volumetric video container.

CyVR Player is GPL-3.0-only. The exact local CyVR_UI source snapshot remains MIT. Matching media/subtitle/Gaussian dependency sources and build instructions accompany the APK.
