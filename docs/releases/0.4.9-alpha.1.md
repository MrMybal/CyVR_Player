# CyVR Player 0.4.9 Alpha 1

DVD-Video and Blu-ray ISO/IMG images now open directly, including seekable Android documents. The reader selects the longest supported movie title and exposes other titles and angles under Playback → Tracks → Disc titles. Titles, chapters, audio/subtitle tracks, DVD aspect/palette data and Blu-ray playlist metadata feed the existing C++/Vulkan player. No whole-image extraction or system mount is required. HTTP(S) ISO playback requires byte ranges and a known size.

The movie clock stays continuous across DVD cells and Blu-ray clips. Chapter seeks resynchronize partial leading audio frames. Title changes retain pause, while title/track choices and navigation survive activity replacement. Both 2D and optional immersive playback use the same controls and rendering path. English remains the default with French translations.

The open-source disc readers and their source archives/notices are included. Interactive menus, protected disc payloads, DVD-Audio/VR, data-disc browsing, interleaved DVD angles and Blu-ray 3D SSIF reconstruction remain unsupported. Blu-ray 3D images explicitly identify their 2D base-view fallback. This release does not qualify every authored disc, UHD profile or sustained thermal workload.
