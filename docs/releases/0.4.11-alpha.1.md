# CyVR Player 0.4.11 Alpha 1

Updates the shared C++/Vulkan interface to CyVR_UI 0.8.0, including cached GPU scene geometry, its original PBR materials and baked lighting. Native 2D remains the default host; optional immersion retains compact/full controls, automatic hiding and independent movie placement. Strictly 2D builds omit the scene resources and OpenXR.

Display → Image quality adds Original, Bilinear and Bicubic sampling, adjustable spatial noise reduction and fine-detail enhancement. They work in Native mode and before CAS/FSR/GSR, including on paused pictures. All taps stay inside the cropped source eye. Noise reduction and detail share a small neighborhood; both are off by default. Disable spatial filters restores the original sampling without changing color corrections or the chosen upscaler.

Enabling these filters reconstructs the displayed window or eye view instead of processing an enlarged full panorama. They add GPU work and do not recover detail absent from the video. Existing image settings and the new filter controls persist through host changes and upgrades. UI text remains separate from video processing.
