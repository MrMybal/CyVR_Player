# CyVR Player 0.4.12 Alpha 1

Adds an independent Video placement page with cinema translation, yaw/pitch/roll rotation, reset and Place in front of me. Explicit placement follows the actual headset inclination. VR180/360 use orientation and zoom because their panorama is rendered at infinity. Optional Keep placement on recenter prefers the runtime's stable STAGE space and compensates known origin changes without moving the controls. If the runtime loses the origin transform, a message asks for a placement adjustment.

The browser now offers List and Card views, saved folder favorites and a sidebar containing Android's granted storage locations. Open a folder adds another system-granted location; USB and other document providers remain subject to Android permissions. Lists page seven items; cards page six. Up to 10,000 entries are listed per folder and 16 favorite folders are retained across host changes.

Previews stay visible during playback. Transient failures are retried instead of permanently cached. Android provider thumbnails and scaled frame extraction are tried first, then a bounded, single-worker FFmpeg fallback supports sources up to 64 megapixels, including 8K. Refresh renews the preview cache. No stream URLs are fetched for previews.

Compact immersive controls gain vector icons, a volume slider and shortcuts to the library, movie information, image quality, placement, cinema, tracks and settings. Playback uses transport icons with hover labels. Language and theme move to Settings; the immersive toggle uses a headset/window icon. Cinema subpages have distinct content panels and icon tabs. The floating dock's icons are centered in their hit regions.

Volume is player-local, bounded to unity gain and smoothly ramped in the audio callback. It preserves the presentation clock, including when muted. Existing audio downmix, image processing and decoder behavior remain available.
