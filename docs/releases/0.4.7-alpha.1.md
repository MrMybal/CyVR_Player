# CyVR Player 0.4.7 Alpha 1

- Add an immersive **Cinema** shortcut and settings for screen width, viewing distance, curvature, height, tilt and roll, with flat, curved, large-screen and reset presets. Moving the controls still leaves the movie in place.
- Add black/dark cinema backgrounds, two bundled 4K CC0 environment photographs, three modeled rooms and passthrough when available. Environment brightness and interface opacity are independent of movie brightness. Unavailable passthrough falls back to the dark background with a message.
- Keep native decoded dimensions on flat and curved compositor layers. CAS, FSR and GSR use the same curved geometry through per-eye projection. Subtitles follow the curved screen on runtimes supporting cylinder layers.
- Add optional **Ambilight**, off by default, with intensity, spread, temporal smoothing, saturation, automatic black-bar exclusion, manual edge inset and reset. A soft video-coloured halo follows the cinema screen and zoom, including native curved layers. It operates entirely on the GPU with a 64 × 36 colour capture and a 128 × 128 glow; the movie retains its own full-resolution layer. Stereo eye colours are averaged in linear light, with floating-point temporal history.
- Retain screen, environment and Ambilight settings across activity changes and upgrades. Existing checkpoints migrate with the new effect disabled. English and French controls share the same C++ UI.

Windows and both Android Alpha variants compile and pass package checks. All nine CTest suites pass, including 693 real Vulkan image checks on PC and Quest 3. New cases cover curved ray intersections across stereo layouts and quality modes, edge colours, black-bar handling, zero-light transparency, temporal convergence, stereo averaging, setting bounds and checkpoint migration. English/French settings were rendered and inspected.

The default APK is installed on Quest 3. The user confirmed the new backgrounds and curved screen work; runtime logs show native cylinder support and curved HEVC/PQ presentation. Ambilight's GPU diagnostic passes on the headset. Worn-headset Ambilight appearance and comfort, all background/filter combinations and sustained high-resolution/thermal performance still require qualification. The glow is a screen surround effect; it does not add physical lighting or shadows to the room. Cinema geometry and Ambilight do not alter VR180/360 or volumetric splat projection.

The app still starts in the Quest-managed Android 2D window; immersion is optional. The separate 2D-only build contains no OpenXR host. CyVR Player remains GPL-3.0-only and the supplied CyVR_UI source remains MIT. The source archive includes the exact foundation snapshot, dependency sources, environment credits and build instructions. This is a testing Alpha.
