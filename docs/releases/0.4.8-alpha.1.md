# CyVR Player 0.4.8 Alpha 1

- Fix repeated stalls when a decoder uses more than twelve hardware image buffers. Keep a bounded 64-image import cache with individual LRU eviction, and reuse Vulkan pipeline compilation results. Preserve native video dimensions and all quality modes.
- Add technical timing breakdowns for image import, GPU completion, native compositor acquisition and host CPU work.
- Detect video layout at each new open from container stereo/spherical metadata and filename conventions, including mono, SBS/TB, eye inversion and VR180/360. Metadata takes priority over naming. Decoded multiview uses its actual stereo packing. Unlabelled ordinary files start in flat 2D, rather than inheriting the previous file's projection.
- Keep manual format controls available. A manual choice survives pause/seek, activity replacement and restart for the current source. **Detect video format** reapplies automatic settings; the status line explains the active selection. Starting another video enables detection again. The app continues to start in the Android 2D host, with explicit entry into immersion.

Ten CTest suites pass, including 33 layout cases, UI/checkpoint migration and the existing 693 Vulkan image checks. Eight generated Matroska/MP4 metadata fixtures give identical results on PC and Quest 3, including real StereoMode/st3d/sv3d records, contradictory names, eye order and unsupported cubemap signalling. English/French format controls were rendered and inspected.

On Quest 3, the original sixteen-buffer regression changed from a 44.2 ms median per operation to approximately 0.20 ms after warm-up, with correct pixels. Tests with sixteen and seventy distinct buffers pass in Native, CAS, FSR and GSR; the larger case verifies bounded individual eviction. These are isolated cache tests, not application FPS figures. An original eight-second 3840 × 2160 AVC 60 FPS clip presents all 480 decoded frames through MediaCodec/AHardwareBuffer/Vulkan without late drops or audio underruns. This does not qualify sustained thermal performance or every source.

The corrected APK is installed on Quest 3. Repeating the user's original low-FPS video remains pending. Detection needs usable metadata or naming; it does not analyse image content or add unsupported projection renderers. Existing media, settings and document grants are preserved when updating with the existing signing identity. CyVR Player remains GPL-3.0-only and the exact supplied CyVR_UI foundation remains MIT. This is a testing Alpha.
