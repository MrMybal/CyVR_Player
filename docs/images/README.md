# CyVR Player screenshots

These images show the real shared C++/Vulkan interface from the local **0.4.15-alpha.1** player build, using **CyVR_UI 0.9.1**. They were captured with the Windows Vulkan inspector using English, the default language, and the Graphite theme.

The library uses demonstration folders, names and media. The video preview is a bundled demo frame; it does not demonstrate Windows hardware playback. Cinema and window screenshots show their settings pages in the 2D host. The compact toolbar is the immersive interface rendered separately from the headset scene, cropped to its visible controls.

| Image | View |
| --- | --- |
| `library.png` | Tile browser and previews |
| `playback.png` | Video preview, timeline and playback controls |
| `image-quality.png` | Upscalers and spatial image filters |
| `cinema.png` | Immersive screen geometry |
| `subtitles.png` | Subtitle appearance |
| `window-controls.png` | Immersive window preferences |
| `compact-controls.png` | Compact immersive playback toolbar |

The demonstration frame comes from **Venice Sunset**, photographed by **Greg Zaal**, provided by **Poly Haven** under **CC0-1.0**. It is already bundled with CyVR_UI as `assets/scenes/venice_sunset.jpg`; source and license information is recorded in that foundation's `assets/scenes/README.md` and `third_party/notices/CC0-1.0.txt`.

Images are PNG files at their captured resolution: 1440 × 990 for full panels and 1024 × 336 for the cropped compact toolbar. No interface elements or labels were composited into the captures.
